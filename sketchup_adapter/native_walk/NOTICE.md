# Walk With Alex — notices

Ported from the native walkthrough of Model Viewer 2 (SketchUp extension by
Bogdan Demchenko). Only the native figure is ported; the browser export is not.

The `assets/` files are copied unchanged from Model Viewer 2's
`walkthrough/assets/`. They are generated from a local derivative of the
Ready Player Me sample avatar distributed with the Three.js examples (MIT:
<https://github.com/mrdoob/three.js/blob/dev/LICENSE>). The motion clips are
derived from the Ready Player Me Animation Library:
<https://github.com/readyplayerme/animation-library/blob/master/LICENSE.md>.

The animation library license restricts redistribution and transfer, including
modified animations, without prior written consent. The public release builder
excludes this entire assets directory. Local pre-existing assets are retained;
the optional avatar service reports that it is unavailable when assets are absent.
